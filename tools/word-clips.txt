# Whole words and syllables to record into audio/words/, one per line.
#
#   powershell -ExecutionPolicy Bypass -File tools/make-sounds-azure.ps1 -WordsFile tools\word-clips.txt
#
# A line is either a word to be read as text ("rabbit"), or a syllable followed by the
# sounds it is made of ("ap = a p"). The second kind is synthesised from those phonemes as
# one syllable, in one breath.
#
# Both halves of that matter. A voice handed a bare "ap" reads it as "A. P." - it is not a
# word, so it gets spelled - and "to" comes back as "two", "i" as "eye", "gg" as "G. G.".
# But playing the recorded /a/ and /p/ one after the other does not fix it either: the two
# were spoken separately, so there is no join between them and it sounds stitched. Asked
# for the phonemes together the voice says one syllable, with the sounds running into each
# other the way they do in speech.
#
# The sound names are the ids in PH.SOUNDS (js/audio.js). To rebuild the list of syllables
# after changing the word bank, open the game and run in the browser console:
#
#   var c=new Map();
#   PH.PICTURES.forEach(w=>{var p=w.g.length>1?w.g:[PH.firstSound(w),w.w.slice(PH.firstSound(w).length)];
#     p.forEach(x=>c.set(x,1));});
#   PH.LEVELS.filter(l=>l.id>=1).forEach(l=>l.words.forEach(w=>
#     PH.soundHintsFor(w).forEach(h=>{if(h[0]!=='/')c.set(h,1);})));
#   console.log([...c.keys()].sort().filter(x=>PH.soundHint(x)[0]!=='/')
#     .map(x=>x+' = '+PH.soundsIn(x).map(s=>s.slice(1)).join(' ')).join('\n'));
#
# That prints a first draft. Check it by eye before trusting it: the spelling rules cannot
# tell that the c of "pencil" is soft, or that the i of "tiger" is long. The corrections
# made by hand are marked below.
