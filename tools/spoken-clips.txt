# Whole words and phrases, recorded so that every device hears the same voice.
#
#   powershell -ExecutionPolicy Bypass -File tools/make-sounds-azure.ps1 \
#     -WordsFile tools\spoken-clips.txt -Spoken -Rate 24000
#
# These go to audio/spoken/, kept apart from the syllables in audio/words/ because the
# same spelling means different things in each: the "to" of tomato is "toh", the word
# "to" is "too". The game looks in spoken/ first.
#
# A line is read as written. The file is named after its letters and nothing else, so
# "Order up!" is saved as order-up.wav and the game slugs what it is about to say the
# same way before looking for it.
#
# 24 kHz rather than 48: nothing in a spoken word lives above 12 kHz, and it halves the
# bytes. Still plain uncompressed PCM - no lossy codec has been anywhere near it.
